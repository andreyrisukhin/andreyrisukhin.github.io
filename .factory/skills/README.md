# Repository skills

`site-design-review` is written for this site.

These four skills are copied unchanged from [emilkowalski/skills](https://github.com/emilkowalski/skills) at commit `0f2e23b` (2026-11-13), under the MIT license in `LICENSE-emilkowalski-skills`:

- `animation-vocabulary`: names for motion effects, for precise prompts.
- `review-animations`: craft review of motion code. Invoke it by name; it does not load on its own.
- `apple-design`: response, interruptibility, spring, and reduced-motion guidance.
- `emil-design-eng`: interaction polish for components.

The iOS, React Native, and library-specific skills from that repository are not installed. Links to `../choreograph/` and `../animation-performance/` in these files point to skills that are not installed here.

`DESIGN.md` wins when these skills disagree with it. The known conflicts are listed in `AGENTS.md` under “UI changes.” To update, copy the four directories again from a newer commit and update the commit above.
